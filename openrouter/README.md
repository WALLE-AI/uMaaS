# OpenRouter UI Study

一个基于 OpenRouter 公开页面进行设计研究后制作的独立、高保真交互原型。它不是 OpenRouter 官方产品，也不包含官方源代码或私有素材。

## 页面与交互

- Landing：首页路由动效、数据指标、产品能力区
- Models：快速模型集合、关键词搜索、能力/模态筛选、价格排序
- Model Detail：左侧九分区导航、Provider、Pricing、性能/可用性、基准、应用、活动、FAQ 与相关推荐
- Providers：隐私/保留/BYOK 策略筛选、流量表格与多 Provider 对比
- Benchmarks：类别标签切换、结果卡片
- Rankings：13 项左侧分区导航，覆盖模型、任务、成本、市场、速度、语言、编程、上下文、工具、图片与应用排行
- Ori Harness：Harness/模型选择、动态 CLI 命令、系统安装切换、配置对比与 FAQ
- Docs：三种代码语言切换、代码复制、目录导航
- 全局：明暗主题、响应式移动导航、Toast、键盘 `/` 搜索与 `Esc` 关闭

直接打开 `index.html` 即可运行，无需安装依赖。图标复用仓库内现有的 Lucide 静态包。

## 设计分析摘要

原站的核心体验来自一致的产品壳与高信息密度，而非强装饰：58px 左右的紧凑顶栏、近黑/暖白的中性色、1px 分隔线、4-5px 小圆角、等宽字体承载数据，以及荧光绿仅用于关键行动与数据状态。目录页采用“筛选器 + 扫描型行列表”，榜单页将时间切换紧邻图表，文档页使用三栏阅读结构。原型保留了这些信息架构与交互原则，并为窄屏重排为单列。
