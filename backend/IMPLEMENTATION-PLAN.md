# 实施计划（任务级）

> 状态：待评审 · 2026-09-08
> 归属：`ARCHITECTURE.md` §9「分期实施」的展开
> **本文是任务分解、依赖顺序、迭代边界与交付判据的真相源**。B/P/M/G/S 五条子序列的
> 排期冲突在此裁决；各任务的**技术内容**仍以对应文档为准，本文只管"什么时候做、做完算什么"。

---

## 1. 先解决一个没人处理过的问题：五条子序列没有共同的时间线

四份设计文档各自给了实施顺序，彼此都合理，但**从未被排到一条线上**：

| 序列 | 出处 | 内容 |
|---|---|---|
| **B0–B7** | `ARCHITECTURE.md` §9 | 骨架 → 身份 → 目录 → 数据平面 → 路由 → 计费 → 管理端 → 私有化 |
| **P1–P7** | `UNIFIED-PROVIDER-INTERFACE.md` §10 | IR → openai 兼容 → 协商与路由 → anthropic → gemini → 多模态 → 异步任务 |
| **M1–M7** | `BILLING-AND-PRICING.md` §10 | 价目 → 成本售价拆分 → 预扣结算 → 对账 → credits → 账单 → 毛利 |
| **G1–G7** | `SELF-HOSTED-GPU-OPERATIONS.md` §9 | Agent → 权重 → 生命周期 → 入路由 → 成本 → 预测扩缩 → 压测 |
| **S0–S4** | `SERVICE-DECOMPOSITION.md` §10 | 模块化纪律 → 装配层 → 拆 Gateway → 拆 Worker → 拆 Infra Agent |

三处冲突必须裁决，否则实现时会撞车：

**① `B5` 与 `M1–M7` 不是同一颗粒度。** B5 一行"计量计费"，M 序列把它拆成七步，且 **M1/M2 必须紧跟 B3，不能等到 B5**——`request_logs` 的字段形状一旦有生产数据就要迁移（计价方案 §10 已论证）。本文据此把 M1/M2 前移。

**② `G5` 与 `M7` 是同一件事的两半。** G5「成本核算与摊销回填」与 M7「毛利视图 + 自建摊销回填」重叠。**裁决：M7 是真相源（它定义字段与不可变约束），G5 是它在 GPU 侧的数据来源（利用率与摊销公式）**，两者同一迭代交付，不拆开。

**③ `S0/S1` 没有前置条件，却决定后面所有代码的形状。** 模块边界纪律与拓扑装配层若不在第一个迭代立好，后面每写一行都在增加将来的返工量。**它们必须在 I0，且不产生任何分布式系统成本**（`SERVICE-DECOMPOSITION.md` §10 已论证）。

另有八项跨领域任务不属于任何序列，此前无人认领，本文记为 **X 系列**。

## 2. 排期原则

1. **风险前置。** 流式转发、预扣结算、协议转换是三处技术风险最高的地方，都排在前半程。先做完一堆 CRUD 再发现流式有坑，代价高一个数量级。
2. **不可逆的先做。** 数据模型（尤其 `request_logs`、`model_prices`）一旦有生产数据，改动成本从"改代码"变成"数据迁移 + 历史重算"。
3. **零成本的纪律先立。** S0/S1、CI 依赖检查、测试基建不引入任何运行时复杂度，却保留全部未来选项。
4. **契约先于实现。** 每个迭代开始前，该迭代涉及的端点契约必须先落到 yaml，前后端同时开工。
5. **每个迭代都能演示。** 判据一律是可观察的行为，不是"代码写完了"。

**人力假设**：2–3 名后端。若只有 1 人，迭代内的并行任务串行化，周数约 ×1.8。**周数是相对规模的量纲，不是承诺**。

## 3. 迭代计划

### I0 · 骨架与纪律（约 2 周）

没有这一层，后面每个迭代都会返工。

| 任务 | 内容 | 出处 | 依赖 | 判据 |
|---|---|---|---|---|
| **B0** | config(koanf) / store 抽象 / goose 迁移 / 信封与错误映射 / slog + request_id / `/healthz` | 架构 §2、§5.1 | — | 服务能起、迁移能跑、`/healthz` 可用 |
| **S0** | 模块化单体四条纪律 + `internal/` 嵌套目录强制 | 拆分 §5 | — | 模块间无直接跨 store 访问 |
| **S1** | 拓扑装配层（local/remote 双实现），**只运行 monolith** | 拆分 §4 | S0 | 接口形状可远程化；切换拓扑无需改业务代码 |
| **X1** | CI：`depguard` 断言依赖图是 DAG | 拆分 §5-规则四 | S0 | 故意造一个环，CI 必须红 |
| **X2** | 测试基建：testcontainers + CI service container | 架构 §7 | B0 | 集成测试跑在真实 PG 上；容器复用生效 |
| **X3** | 观测底座：OpenTelemetry + Prometheus exporter，`request_id` 贯穿 | 架构 §2.5 | B0 | 一次请求的 trace 可端到端串起来 |
| **X4** | 部署流水线：迁移作为独立步骤（**不在服务启动时自动执行**）；反代 `proxy_buffering off` | 架构 §8、§6.1 | B0 | 多副本同时启动不竞争迁移锁 |

> **X4 的 `proxy_buffering off` 现在就要做。** 它在 I3 才会显现价值，但那时如果漏了，
> 现象是"流式变成了慢的非流式"，而排查方向会先怀疑应用层——白花一天。

**并行的非代码任务**：`selfhosted/qwen3-max` 从 `canary` 退回 `draft`（计价方案 §11-G）。它现在在接真实流量但无价可计，且**事后无法追补**。这一条不占工时，但拖着每天都在漏。

| 任务 | 内容 | 出处 | 依赖 | 判据 |

## 4. 关键依赖链

```
I0 ─┬─ S0 ─ S1 ──────────────────────────────────┐
    └─ B0 ─┬─ B1 ─────────────────────────┐      │
           ├─ X5(admin身份) ──────────────┤      │
           └─ B2 ─┬─ M1 ─ M1a ─ M1b ──────┤      │
                  │                        │      │
                  P1 ─ B3 ─ M2 ─┬─ P2 ─ P3 ┼─ B4 │
                                │          │      │
                                └─ M3 ─ M4 ─ M5 ─ B5
                                              │
                                              ├─ I6（管理端 34 端点）
                                              │
                                   G1 ─ G2 ─ G3 ─ G4 ─ G5+M7
```

四条**不能违反**的顺序约束：

1. **M2 ≤ I3**：`request_logs` 有生产数据后再改就是迁移
2. **M1 ≤ B2 上线**：目录页展示的价格必须来自价目表，不能先用假数据（否则 M1b 的"同源"判据无从验证）
3. **G4 > P3**：自建接入路由依赖评分引擎存在
4. **X5 < I6**：34 个端点的鉴权主体必须先存在

## 5. 每个迭代的完成定义（DoD）

除各任务判据外，以下四条对每个迭代都成立：

- [ ] 涉及的端点契约已落到 yaml，前后端一致
- [ ] 集成测试跑在 testcontainers 起的真实 Postgres 上（不是 SQLite，架构 §7）
- [ ] `monolith` 拓扑能启动并跑通冒烟测试（拆分 §7——装配层会悄悄腐化）
- [ ] 新增的破坏性操作已标 `destructive` 并写入审计

## 6. 风险登记

| 风险 | 迭代 | 前置缓解 |
|---|---|---|
| **流式转发链路有坑**（缓冲、超时、取消） | I3 | 反代 `proxy_buffering off` 在 I0 就配好；I3 结束必须演示断流场景 |
| **预扣悬挂造成坏账** | I5 | M3 强制三种故障注入测试；M4 的对账是第二道防线 |
| **抽象位置错误**（每个厂商都要写代码） | I4 | P2 判据"第三个厂商零代码"不放水，此时返工最便宜 |
| **GPU 记账漂移** | I7 | G1 的三方对账与 Agent 同期交付，不后置 |
| **自建定价站不住**（×0.7 在低利用率下亏损） | I8 | G5+M7 紧跟 G4，不推到最后 |
| **I6 规模被低估** | I6 | 已按 34 端点估算；其中 B6b 依赖 M1a、X9、X10 三项前置，缺一个就会阻塞 |
